# 家底快照助手

「家底快照」账本系统的助手。你可以像跟人说话一样，让它**记一期账、报一个数、解释这个数是怎么来的、回答系统怎么用**。

它不重算任何数字：折算、汇总、收益、两期对比、趋势，一律取系统算好的结果。

---

## 一、它是什么

| 你能让它做的事 | 举个例子 |
|---|---|
| **盘一期** | 「把这份清单录一期，日期 2026-10-05」+ 粘贴或指定你的表格 |
| **问数** | 「我现在净资产多少」·「按平台看看占比」·「这个月跟上个月比涨跌多少」 |
| **看趋势** | 「我这几个月的走势」·「理财收益怎么样，哪些账户拖后腿」 |
| **答疑** | 「这个系统怎么用」·「本金和收益是怎么算的」·「数据存在哪、怎么备份」 |

也可以显式点名调用：`/asset-snapshot-skill`。

---

## 二、用之前注意这几件事

**1. 账本服务得先开着。**
默认地址 `127.0.0.1:5188`，在账本目录执行 `npm start` 就能起。
服务没跑时它**只会告诉你启动命令，不会替你启动**（替你起会留下占端口的后台进程，反而让你之后重启失败）。

**2. 通常不用配任何东西。**
它就认「当前目录往上找到的那个账本」。如果你平时就在账本目录里工作，直接说话即可。
只有从别的地方调用时，才需要固定一次账本位置，之后就一直记得：

```bash
python3 ~/.workbuddy/skills/asset-snapshot-skill/scripts/doctor.py --remember
```

**3. 钱的事，它一定先问你。**
凡是会改动账本的操作（建账户、改账户、存快照……），它都会**先把「将要写入什么」完整摆给你看**，你点头才落库。
其中改不回来的操作（删账户、删快照、改本位币、整表覆盖汇率、从备份恢复……）会要求**二次确认**，并且**动手前自动备份一次**；备份失败就不执行。

**4. 有几件事它不做，得你自己来。**
清空账本、灌演示数据、执行数据库迁移、从外部网站刷新汇率、改任意设置项 —— 这些会改变之后所有折算的基准，或不可逆，必须由你在终端亲手执行。

**5. 它不会碰你的数据库文件。**
只通过本机接口读写。它**不会向你索要令牌**，令牌也绝不会出现在它的任何输出里。

**6. 系统没提供的分析，它能算，但会标出来。**
比如归因拆解、最大回撤这类算法系统本身没有。你要它算，它会算，但结果会明确标成
**非系统口径 · 未落库 · 不出现在系统界面** —— 免得你把它当成系统出的数。

## 三、怎么用

### 盘一期（流程最完整的一条）

你说「把这份清单录一期，日期 XX」并把表格给它（粘贴、或给个文件路径都行），然后：

1. 它先跟你**确认口径**：填**当前实际价值**（不是买入价），负债也填**正数**；再确认盘点日期。
2. **对账户** —— 如果你的账本里有同名账户，它**不会自己挑一个**，会把候选列出来让你指认。
3. 调系统做一次**试算**（这一步不动数据）。
4. **把「将写入清单」完整摆给你看**：写哪本账、哪个日期、哪些账户、各自多少钱。
5. 你确认后才落库，回执里会回显写进了哪本账。

### 问数

直接说就行，不用背命令：

> 「我现在净资产多少」 · 「按平台/按分类看看占比」 · 「和上个月比涨跌多少」
> 「收益怎么样」 · 「哪些账户在跌」 · 「我这几个月的趋势」

它会把数字摆出来，并说明**这个数是怎么来的、为什么是这个数**。查不到的东西它会直说，不会编。
能让图说清的（结构、走势、两期对比）它会直接给图；词典式的东西（账户清单、汇率表）还是给文本，图反而更难读。

### 答疑

问「这个系统怎么用」之类的，它是**从账本包内的使用手册正文**里回答的，不是凭印象。手册里没写的，它会告诉你没写。

## 四、常见问题

**问：我说了话，它没反应？**
技能是按**任务**触发的，描述里带上「盘点 / 录一期 / 净资产 / 占比 / 趋势 / 收益 / 这个功能怎么用」这类词最容易命中。
刚装好还需要**新开一个会话**，平台才会加载到它。

**问：它说连不上服务怎么办？**
就是账本服务没在跑。到账本目录执行 `npm start`，看到启动成功的提示后再试。
它不会替你起服务，这是有意为之 —— 替你起的那个进程会一直在后台占着端口，你自己再启动就会失败。

**问：它算的数字和我自己在系统界面上看到的不一样？**
先看它有没有标注「非系统口径」—— 有标注的说明那是**你额外要它算的**、系统本身不提供的指标。
没有标注的数字一定与系统一致（它自己不重算）。如果确实对不上，让它跑一次自检：它会核对服务地址、数据目录、数据模式，把实际情况列出来。

**问：占比是系统里的数吗？**
不是。系统本身不提供占比，它是你问了之后技能额外算的 —— 所以一定带「非系统口径」标注，
并写明分母是什么（比如「占本期净资产」）。你不问，它不会给。

**问：收益为什么显示「不可用」？**
常见两种原因：这个账户**没开启本金跟踪**，或者这是**第一期**、还没有可比较的基准期。
技能会告诉你是哪一种，而不是给个 0 糊过去。

**问：录入时它说「同名账户，请指认」？**
你的账本里有两个以上同名的账户（比如都叫「活期」）。它不猜，会把候选列出来，你说哪个就是哪个。

**问：这次有些账户不想填，行不行？**
分两种：**以前填过的**，空着就自动**沿用上一期的值**；**从来没有金额的**，会算作「未填写」，**不会写进这一期**。
保存前它会把「本期没填的账户」列出来，需要你**明确确认**才继续。

**问：我改了账户名，历史快照里的名字会跟着变吗？**
不会。快照冻结了当时的信息，跨期对比按账户的**内部编号**做，所以改名、归档都不会改写历史。

**问：数据存在哪？怎么备份？**
它可以说清楚，也可以**立刻帮你做一次备份**。要恢复的话是「改不回来」的操作，它会要求二次确认并先自动备份一次。

**问：它给我画的图，数字准吗？**
图上的数字跟系统界面一致（它自己不重算，只是把系统的数换个样子摆出来）。
**唯一例外**是「占比」这类系统本身没有的指标 —— 图上会写明「非系统口径 · 未落库 · 不出现在系统界面」，
并交代分母是什么。看到这段字就知道那是额外算的，不是系统出的数。
另外：图只在对话里出现，不会生成文件，也不会被写进你的账本。

**问：它会不会偷偷改我的数据？**
不会。改动你账本的操作一律先给你看清单、要你点头；不可逆的还要二次确认。只读的问答、试算、导入预览不会写入任何东西。

**问：能清空账本、换成演示数据吗？**
不能。这类操作会清掉你的真实记录，技能**没有这个能力**，需要你自己在终端执行账本自带的命令。

**问：装在别的平台能用吗？**
能。它是纯 Python 标准库（不需要装任何依赖），只要求那个平台能运行脚本、能访问本机账本接口。
