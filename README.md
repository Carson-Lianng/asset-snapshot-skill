# 家底快照助手 · 技能仓

「[家底快照](https://github.com/Carson-Lianng/asset-snapshot)」账本系统的配套 Agent 技能 ——
**独立交付、独立成仓**（它不在应用安装包里，也不在应用的源码仓里）。

| 想找什么 | 去哪儿 |
|---|---|
| 应用本体（本机运行的账本系统） | <https://github.com/Carson-Lianng/asset-snapshot> |
| 官网与在线试用（只读演示） | <https://carson-lianng.github.io/asset-snapshot/> |

---

## 这是什么

把本机运行的账本系统包成一个「说人话就能用」的入口：**录一期 · 问数 · 看趋势 · 答疑**。

它**不重算任何数字** —— 折算、汇总、收益、两期对比、趋势一律取系统算好的结果。
系统本身没有的指标（如占比）它会算，但会明确标成
**非系统口径 · 未落库 · 不出现在系统界面**，并写明分母是什么。

它**不碰数据库文件**，只跟本机 HTTP 接口对话；也**不会向你索要令牌**。

## 装法

**方式一：拷目录（推荐）**

```bash
git clone https://github.com/Carson-Lianng/asset-snapshot-skill
# 然后把 family-snapshot/ 整个目录拷进平台的技能目录
# WorkBuddy 用户级：~/.workbuddy/skills/
```

**方式二：让 Agent 自己装**

把下面这段话发给你的 Agent：

```text
帮我把这个技能装到你的技能目录：
https://github.com/Carson-Lianng/asset-snapshot-skill

然后帮我盘这一期 —— 附件是我 10 月 5 号的账户截图。
按截图里的余额先列一份清单给我看，我点头之后再落库。
```

> ⚠ 装好之后**新开一个会话**，平台才会加载到它。

## 前提：账本服务得先开着

默认地址 `127.0.0.1:5188`，在账本目录执行 `npm start` 就能起。

服务没跑时它**只会告诉你怎么启动，不会替你启动** —— 替你起会留下一个占着端口的后台进程，
反而让你之后重启失败。

## 仓内结构

```
family-snapshot/
├── SKILL.md            技能入口：触发词 + 硬性规则（平台读的是它）
├── README.md           面向使用者的完整说明（能力 / 注意事项 / 常见问题）
├── references/         端点清单 · 常用食谱 · 安全分级 · 使用手册索引
└── scripts/            纯 Python 标准库，只调本机 /api/*
```

## 它不做的事

- **不替你启动或停止账本服务**（占端口的后台进程会让你之后重启失败）
- **不直连数据库文件**（绕过单位换算、口径冻结、引用校验与自动备份）
- **不能清空账本、灌演示数据、跑迁移、改任意设置项** —— 这些要你在终端亲手执行
- **不可逆的写操作**（删账户 / 删快照 / 改本位币 / 从备份恢复…）要二次确认，且动手前自动备份一次
- **不编数字**：查不到就直说；手册里没写的就告诉你没写
